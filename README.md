# Machine Learning Classification

## Project Title

**Heart Disease Prediction using Machine Learning**

## About the Project

This project demonstrates a Machine Learning classification approach using Python and a heart disease dataset.

The project uses different classification algorithms to predict whether a person has heart disease or not.

The following Machine Learning models are implemented:

- Decision Tree
- Random Forest
- Logistic Regression
- K-Nearest Neighbors (KNN)

The performance of these models is compared using different evaluation metrics.

## Objectives

- Load the heart disease dataset.
- Explore the dataset and target values.
- Separate features and target variables.
- Split the data into training and testing sets.
- Build a Decision Tree classification model.
- Visualize the Decision Tree.
- Test different Decision Tree depths.
- Build a Random Forest classification model.
- Analyze feature importance.
- Test different Random Forest parameters.
- Compare different Machine Learning models.

## Technologies Used

- Python 
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Dataset

The project uses the following dataset:

`decisiontree.csv`

The `target` column is used as the target variable.

The target represents:

- `0` → No Disease
- `1` → Disease
